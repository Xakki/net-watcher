# Research policy

Net Watcher is non-commercial observational network research. Its strongest permissible interpretation is association: observations cannot establish cause, intent, responsibility, or maliciousness.

## Time model

Methodology separates registration-event time, routing-observation time, and validation-snapshot time. Conclusions must state which clock supports each observation and preserve uncertainty.

## Current scope

Work is public/synthetic-only. Gated source access is not approved; real-data execution is unavailable. No research data or research-derived output may flow into a product or commercial system.

## Output limits

Any future output requires separate approval and must be aggregate and uncertainty-aware. Raw, row-level, subject-searchable, organization/contact, rare-case, reconstruction, minimized-event, and audit outputs are prohibited. Public reproducibility may contain only public/synthetic code, configuration, manifests, fixtures, and aggregate build instructions.

Corrections use GitHub Issues and must minimize sensitive detail. Publication requires review of exact bytes and a separate human decision.
