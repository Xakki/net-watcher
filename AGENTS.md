# Agent instructions

Net Watcher is a public, non-commercial observational network-research landing. Current work is public/synthetic-only; no study or real-data execution is active.

## Working rules

- Use `make <target>` for repository operations and run `make verify` before hand-off.
- Keep the served site static, English-only, script-free, form-free, and free of external assets or visitor measurement.
- Treat `publication-boundary.json` as the exact tracked and served publication contract.
- Use only project-local `NW-*` cards. Card state is its directory; never add histories, machine paths, commit identifiers, reviewer identities, correspondence, or private evidence.
- Add files with explicit Git paths. Commit subjects use `<scope>: <imperative summary>` and the sole trailer `Agent: project-governance`.
- Do not push, deploy, alter DNS/TLS, select a provider, or imply publication approval.

## Data and publication boundary

Do not read or publish ignored local namespaces. Never add credentials; real, restricted, raw, row-level, minimized-event, quarantine, audit, deletion, or reproducibility evidence; host inventory; private review material; vendor evidence; or account/application procedures. Research data and research-derived output must not flow into product or commercial systems. Future output requires separate approval and must be aggregate and uncertainty-aware.

Publication requires an approved provider, exact-artifact independent review, a green `make publish-check`, and separate human authorization. GitHub Issues is the correction endpoint.
