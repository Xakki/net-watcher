# Roadmap

## 1. Existing draft baseline

The static English draft has no JavaScript, forms, external assets, collection, or results. Local verification remains the baseline.

## 2. Standalone governance

Complete the standalone-governance card: self-contained documentation, public Kanban, agent instructions, exact allowlists, and stronger verifiers.

## 3. Artifact review

Complete the draft-freeze and independent-review cards. Independent review covers the exact landing bytes, methodology, privacy, security, accessibility, and publication boundary.

## 4. Publication decision

Complete the provider-selection card. The provider changes from `null` only after exact approval; GitHub Issues remains the correction endpoint.

## 5. Release

Release begins only after review and provider gates. DNS, TLS, hosting, and publication remain distinct human-authorized actions.

## 6. Future research

Future aggregate publication remains inactive until source access, protocol, aggregate outputs, and review are separately approved. No current approval, ingestion, analysis, or results publication is implied.
