# Independent citation review pattern

Use this after a documentation-only landscape brief is drafted. Verify every
material sentence against the exact cited first-party page, with special care
for policy scope: generic service terms, bulk-data terms, and historical-report
terms are not interchangeable. Check that each inline citation ID has exactly
one matching source-list URL and that every listed source is cited; run the
ledger verifier, but do not mistake a passing structural check for factual
support. If exact question or estimand details are unavailable, preserve the
brief's schema-level caveat and return REQUEST CHANGES rather than approval.
Named families must remain conditional future considerations, and temporary
browser captures used when extraction is unavailable must be deleted before
handoff.
